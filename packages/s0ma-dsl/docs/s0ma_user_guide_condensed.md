# Retired: s0ma_user_guide_condensed.md

This was a hand-written abridgement of the s0ma User Guide, last touched
2026-04-24. It was retired on 2026-08-30 rather than merged, because it held
nothing the full guide did not: every section here was a shortened copy of the
section with the same name, so keeping it meant keeping the same facts in two
documents that no gate compared — which is how the full guide came to exist in
two drifted copies in the first place.

**The full guide:**
[`packages/s0ma-core/docs/s0ma_user_guide.md`](../../s0ma-core/docs/s0ma_user_guide.md).

**If you wanted the short version**, there is a better one than a four-month-old
abridgement, and it is kept honest by the build:

- [`survival_card.md`](survival_card.md) — the smallest thing that is still
  useful, size-capped by a gate.
- [the quick reference](../../../docs/reference/quick-reference-readable.md) — every
  declaration line by line, generated from the language; look topics up there.
- The authoring server's `learn_s0ma` tool, which answers a question with the
  one topic that addresses it and says which release and documentation snapshot
  the answer came from.

This pointer file is scheduled for deletion once inbound links are updated.
